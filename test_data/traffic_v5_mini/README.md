# Мини-выборка для тестового задания

Классы перечислены в `classes.txt`; номер класса в YOLO-разметке соответствует номеру строки, начиная с нуля.

Проверьте каждое изображение и исправьте или дополните разметку. В наборе встречаются как корректные, так и неполные или отсутствующие аннотации. Не считайте отсутствие `.txt` автоматически подтверждением, что на изображении нет целевых объектов. Сохраните исходные файлы и запишите исправленный набор в отдельный каталог.

Формат бокса YOLO:

```text
class_id x_center y_center width height
```

Координаты нормализованы относительно ширины и высоты изображения.
